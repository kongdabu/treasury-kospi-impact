# Bond Market Analysis — 국채선물 내재 시점 역산법

미국채 시장 가격에서 "시장이 보는 금리 전환 시점"을 역산하는 방법론. 채권 전문가가 사용한다.

## 왜 이 접근인가
선물·곡선 가격은 시장 참여자 전체의 베팅이 집약된 결과다. 점도표가 "연준의 의도"라면 선물 곡선은 "시장의 컨센서스"다. 단, 가격은 순수 금리 기대에 **텀 프리미엄·수급 왜곡**이 섞여 있으므로 분해해야 정확한 시점 신호를 얻는다.

## 데이터 소스
- **수익률 곡선:** 2Y·5Y·10Y·30Y 금리, 2s10s·3m10y 스프레드
- **국채선물:** ZT(2Y)·ZF(5Y)·ZN(10Y)·ZB(30Y) 가격·기간구조, 내재 수익률
- **분해 지표:** TIPS 실질금리, BEI(기대인플레), ACM 텀 프리미엄
- **포지셔닝·수급:** CFTC COT 투기적 순포지션, 국채 발행 일정, QT(대차대조표 축소) 속도

> WebSearch/WebFetch로 최신 종가·스프레드를 확보한다. 실시간 불가 시 최근 종가 기준 명시.

## 분석 워크플로우
1. **곡선 진단** — 형태(정상/평탄/역전)와 스프레드 추세. 역전은 시점 신호이자 경기 신호이므로 분리 해석
2. **선물 기간구조** — 근월~원월 내재 수익률에서 시장 내재 정책 경로를 추출
3. **분해** — "가격 = 금리 기대 + 텀 프리미엄"으로 나눠 순수 기대만 추림. 실질금리/BEI로 명목 변화의 원인(실질 vs 인플레) 구분
4. **포지셔닝·수급 점검** — 과도한 쏠림, 대규모 발행/QT가 수익률을 정책과 무관하게 왜곡하는지 평가
5. **시장 내재 시점 시나리오** — 표준 포맷으로 작성 + 정책 경로와의 괴리 명시

## 핵심 산출물: 괴리 분석
